# Chiyumi

Chiyumi는 디스코드 서버 운영과 놀이 기능을 함께 제공하는 Node.js 기반 디스코드 봇입니다.

> 모든 명령어는 슬래시 명령어로 제공되며, 처음 사용 시 이용약관·개인정보 처리방침 동의 절차를 거칩니다.

## 주요 명령어

### 🛡️ 서버 관리

| 명령어 | 설명 |
|--------|------|
| `/인증` | 버튼 클릭으로 인증 완료 → 지정 역할 자동 지급 |
| `/공지` | 지정 채널에 임베드 공지 전송 |
| `/로그` | 메시지 삭제·수정, 음성 입퇴장, 욕설·도배·레이드 알림 등 서버 활동을 채널에 기록 |
| `/입퇴장` | 멤버 입·퇴장 시 커스텀 문구로 채널 알림 (입장·퇴장 채널 각각 지정 가능) |
| `/검열` | 욕설 자동 감지 및 삭제 / 도배 감지 (1~5단계) / 레이드 감지 (10초 내 5명 이상 입장 시 채널 잠금·초대 링크 정지·자동 경보 해제) |
| `/경고` | 경고 지급·취소·조회·초기화 및 경고 횟수별 역할 부여·뮤트·킥·밴 자동 제재 설정 |
| `/티켓` | 비공개 스레드 티켓 시스템 (관리자용 추가·닫기·txt 저장·삭제 버튼 포함) |
| `/방송알림` | 유튜브 라이브·업로드, 치지직, SOOP 방송 시작 알림 설정 |
| `/밴` / `/킥` | 서버에서 사용자 차단·추방 |

### 💰 경제

| 명령어 | 설명 |
|--------|------|
| `/출석` | 하루 1회 치유미코인 + 경험치 지급 |
| `/코인` | 치유미코인 잔액 조회 |
| `/도박` | 슬롯머신·홀짝·숫자맞추기·블랙잭·가위바위보 (코인 베팅) |
| `/주식` | 가상 주식 매수·매도·포트폴리오 조회 (주가 매일 자정 KST 자동 변동) |
| `/은행` | 예금·출금·대출 신청·상환·파산 신청 (예금 이자 1%/일, 대출 복리 5%/일) |

### 🎮 게임 & 육성

| 명령어 | 설명 |
|--------|------|
| `/끝말잇기` | 채널에서 파티 모집 후 스레드에서 봇과 함께 끝말잇기, 제한시간 초과 시 탈락 |
| `/키우기` | 가상 고양이 입양 — 밥·씻기·놀기(하루 1회), 입양일로부터 경과 시간에 따라 성장 |

### 🤖 AI 채팅

"유미야"로 시작하는 메시지를 보내면 치유미가 AI로 응답합니다. Groq → OpenRouter → Mistral 순서로 자동 폴백되며, 채널별로 대화 맥락을 유지합니다.

### 📊 조회 & 유틸리티

| 명령어 | 설명 |
|--------|------|
| `/순위` | 채팅·음성 활동 기반 레벨·경험치 카드 이미지 및 서버 순위 조회 |
| `/전적검색` | 리그 오브 레전드 최근 전적·라인별 매치업·티어 조회 (Riot Games API) |
| `/문의` | 유저 신고·피드백·버그 신고를 모달로 접수해 운영 채널로 전달 |
| `/도움말` | 카테고리별 전체 명령어 안내 |
| `/핑` | 봇 응답 속도 확인 |

## 개발 정보

- Node.js
- discord.js
- @napi-rs/canvas (순위 카드 이미지 생성)
- groq-sdk (AI 채팅 — 기본 API)
- openai (AI 채팅 — OpenRouter·Mistral 폴백)
- google-auth-library (구글 시트 데이터 백업/뷰어 동기화, `.env`에 `GOOGLE_SHEET_ID`/`GOOGLE_SERVICE_ACCOUNT_EMAIL`/`GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY` 설정 시에만 동작)
- 국립국어원 우리말샘 Open API (끝말잇기 단어 사전 검증, `.env`에 `WORDCHAIN_DICT_API_KEY` 설정 시에만 동작, 미설정 시 끝말잇기 규칙만으로 검증)
