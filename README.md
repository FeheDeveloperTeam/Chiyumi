# Chiyumi

Chiyumi는 디스코드 서버 운영과 놀이 기능을 함께 제공하는 Node.js 기반 디스코드 봇입니다.

> 모든 명령어는 슬래시 명령어로 제공되며, 처음 사용 시 [이용약관](https://www.fehe.dev/DiscordBot/Chiyumi/terms)·[개인정보 처리방침](https://www.fehe.dev/DiscordBot/Chiyumi/privacy) 동의 절차를 거칩니다.
>
> [오류 코드 안내](https://www.fehe.dev/DiscordBot/Chiyumi/errors)

## 주요 명령어

### 🛡️ 서버 관리

| 명령어 | 설명 |
|--------|------|
| `/인증` | 버튼 클릭으로 인증 완료 → 지정 역할 자동 지급 |
| `/공지` | 지정 채널에 임베드 공지 전송 |
| `/로그` | 메시지 삭제·수정, 음성 입퇴장, 욕설·도배·레이드 알림·레이드 공지(서버원)·해제 공지 등 항목별 채널 개별 설정 및 일괄 관리 |
| `/입퇴장` | 멤버 입·퇴장 시 커스텀 문구로 채널 알림 (입장·퇴장 채널 각각 지정 가능) |
| `/검열` | 욕설 자동 감지 및 삭제 / 도배 감지 (1~5단계) / 레이드 감지 (10초 안에 동일 닉네임 멤버 5명 이상 입장 시 채널 잠금·초대 링크 정지·서버원 자동 경보·관리자 해제) |
| `/경고` | 경고 지급·취소·조회·초기화 및 경고 횟수별 역할 부여·뮤트·킥·밴 자동 제재 설정 |
| `/티켓` | 비공개 스레드 티켓 시스템 (관리자용 추가·닫기·txt 저장·삭제 버튼 포함) |
| `/방송알림` | 유튜브 라이브·업로드, 치지직, SOOP 방송 시작 알림 설정 (서버 관리 권한 필요, DM 불가). 5분마다 확인하며 확인이 겹쳐 돌지 않음. 모든 외부 조회는 15초 시간 제한. 보낸 알림은 봇 전용 `data/streamAlertSent.json`(알림 ID+영상/방송 ID, 30일 보관)에 보내기 전에 기록해 사이트 쓰기와 겹쳐도 다시 보내지 않고, 라이브는 방송 ID(유튜브 영상 ID·치지직 liveId·SOOP broad_no) 기준이라 같은 방송이 끊겼다 다시 켜져도 한 번만 알림. 방송 알림 확인은 호스팅 서버(`/home/container`)에서만 돌고 PC에서는 `STREAM_ALERTS_ENABLED=1`일 때만 돎. 알림은 nonce(`enforceNonce`)로 보내 discord.js 재전송에도 한 번만 올라감. 라이브는 꺼짐→켜짐일 때 1회, 2번 연속 꺼져야 종료로 보고 조회 실패는 상태를 바꾸지 않음. 업로드는 영상 페이지의 `isLiveContent`로 라이브·다시보기를 빼고(봇 서버에서는 YouTube가 영상 페이지를 막아 채널의 라이브/동영상/Shorts 탭으로 구분), 프리미어는 공개 후 알림. 라이브 알림 문구는 `{name}`·`{title}`(방송 제목, 유튜브는 페이지에 없으면 oEmbed)·`{url}`을 쓸 수 있고, `{url}`을 안 쓰면 링크가 붙어 디스코드 카드로 제목이 보임. 봇이 켜질 때 `[방송알림] 시작 점검` 로그로 서버에서 유튜브를 읽을 수 있는지 남김. 유튜브 채널은 UC ID로 저장(예전 핸들은 자동 변환). 테스트 알림은 멘션이 울리지 않음. 치지직은 `service/v2/.../live-detail`, SOOP은 `broad` 유무로 방송 여부 판단 |
| `/밴` / `/킥` | 서버에서 사용자 차단·추방 |
| `/채팅청소` | 현재 채널의 최근 메시지를 최대 100개까지 일괄 삭제 (메시지 관리 권한 필요, 14일 지난 메시지는 하나씩 삭제) |
| `/레벨업알림설정` | 레벨업 알림 설정 패널(나만 보기). 알림 켜기·끄기, 알림 채널 선택 또는 레벨업한 채널에서 알리기, 문구 수정(`{유저}`·`{레벨}` 치환)·기본 문구로 되돌리기, 미리보기를 한 화면에서 처리 (서버 관리 권한 필요). 관리자가 켜기 전에는 레벨업 알림을 보내지 않음 |
| `/유미채널설정` | "유미야" AI 대화를 쓸 수 있는 채널 설정 패널(나만 보기). 채널 추가(아직 추가하지 않은 채널만 보이는 선택 메뉴, 25개씩 쪽 넘김, 여러 개 선택), 채널 제거(등록된 채널만 보임), 모두 삭제(확인 후)를 한 화면에서 처리 (서버 관리 권한 필요, 최대 25개, 지정 채널 안의 스레드 포함) |

### 🤖 AI 채팅

"유미야"로 시작하는 메시지를 보내면 치유미가 AI로 응답합니다. 서버에서는 관리자가 `/유미채널설정`으로 지정한 채널들(여러 개 가능, 그 안의 스레드 포함)에서만 동작하고, 지정 전에는 아무도 쓸 수 없습니다. 다른 곳에서 부르면 일반 사용자에게는 서버 관리진 문의를(AI-007), 관리자에게는 채널 지정을 안내하고(AI-007/AI-008) 안내는 10초 뒤 지워집니다. 채널 목록은 `data/guildConfig.json`의 `aiChannelIds`(채널 ID 배열)에 저장됩니다. Groq(`qwen/qwen3.8-27b`(무료 등급 분당 출력 1000토큰 한도라 `max_tokens` 900, 한도 초과 시 재시도 없이 다음 모델로) → `openai/gpt-oss-120b`) → OpenRouter(`google/gemma-4-31b-it:free`) → Mistral 순서로 자동 폴백되며(모델 목록은 `groqChat.js`의 `AI_PROVIDERS`, 실패한 단계는 `[AI] … 실패` 로그로 남음), 채널별로 대화 맥락을 유지합니다. 응답은 문장마다 끝을 "냥"으로 보정하며, 모델이 섞는 "~당/~징/~용" 같은 애교 어미도 "~다냥/~지냥/~요냥"으로 바꿉니다(`src/utils/groqChat.js`의 `applyNyaEndings`).

**기억 기능** — 유저별로 정보를 Supabase에 영구 저장하며, 이후 대화에 자동 반영됩니다.

| 명령어 | 설명 |
|--------|------|
| `유미야 기억해 [내용]` | 내용을 기억에 저장 (최대 10개, 개발자 무제한) |
| `유미야 기억 목록` | 저장된 기억 목록 조회 |
| `유미야 기억 삭제 [번호]` | 특정 번호 기억 삭제 |
| `유미야 기억 수정 [번호] [새 내용]` | 특정 번호 기억 수정 |
| `유미야 기억 모두 삭제` | 모든 기억 삭제 |

## 개발 정보

- **서버 전용**: 모든 슬래시 명령어는 서버에서만 보이고 실행됩니다(`contexts: [0]`, `integration_types: [0]`, `src/utils/guildOnly.js`의 `toGuildOnlyCommandJSON`으로 등록). 앱의 사용자 설치(User Install)는 꺼져 있고, DM 메시지 인텐트도 받지 않습니다. 서버 밖이나 봇이 없는 서버에서 온 요청은 `interactionCreate`가 GUILD-001로 막습니다.
- 환경변수: `.env`는 로컬과 CoredLab 서버 두 곳에 같은 키를 둔다(예외: `DISCORD_TOKEN`은 서버에서 CoredLab 패널 시작 변수). 키를 추가·변경하면 두 곳 모두 고친다.
- 호스팅(CoredLab) 제어: `node scripts/coredlab.js status | restart | start | stop | logs [초]` — `.env`의 `COREDLAB_API_KEY`, `COREDLAB_SERVER_ID`(선택 `COREDLAB_BASE_URL`, 기본 `https://host.coredlabgame.cloud`)를 사용합니다.

- Node.js
- discord.js
- @napi-rs/canvas (순위 카드 이미지 생성)
- groq-sdk (AI 채팅 — 기본 API)
- openai (AI 채팅 — OpenRouter·Mistral 폴백)
- @supabase/supabase-js (AI 기억 저장)
- google-auth-library (구글 시트 데이터 백업/뷰어 동기화, `.env`에 `GOOGLE_SHEET_ID`/`GOOGLE_SERVICE_ACCOUNT_EMAIL`/`GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY` 설정 시에만 동작)
- 국립국어원 우리말샘 Open API (끝말잇기 단어 사전 검증, `.env`에 `WORDCHAIN_DICT_API_KEY` 설정 시에만 동작, 미설정 시 끝말잇기 규칙만으로 검증)
- Open-Meteo 날씨·대기질 API (날씨·미세먼지 조회, API 키 불필요) → 실패 시 MET Norway Locationforecast API로 전환 (API 키 불필요)
- HenrikDev 발로란트 API (비공식, `/전적검색` 발로란트. `.env`의 `HENRIK_API_KEY`(대시보드 https://api.henrikdev.xyz/dashboard 에서 Valorant·Standard 30회/분으로 발급) 사용, 키가 없으면 발로란트 버튼을 숨긴다. 데스매치는 플레이어마다 팀이 하나씩 와서 팀이 2개일 때만 팀전으로 보고, 개인전은 순위(placement)로 표시한다. 라이엇 공식 발로란트 API는 승인된 서비스 키 전용이라 `RIOT_API_KEY`로는 403) + valorant-api.com (요원·맵·티어 한국어 이름·아이콘, 키 불필요, 하루 캐시)
- 기상청 API (강수 레이더·지진 지도, `.env`의 `KMA_API_KEY` 사용. 공공데이터포털 지진정보는 이 키로 동작하지만 기상청 API 허브 레이더는 401이라 RainViewer로 대체)
- 레이더·지진·태풍 지도의 배경 지도는 외부 타일 없이 `src/utils/baseMap.js`가 `src/assets/eastAsiaMap.json`(Natural Earth 1:10m, 퍼블릭 도메인, 경도 110~149°·위도 20~50°만 잘라 단순화)으로 직접 그린다. 이전에 쓰던 CARTO 무료 타일은 API 키를 요구하도록 바뀌어 "API KEY REQUIRED" 타일만 내려온다
- 호스팅 컨테이너의 IPv6 경로가 불안정해서 `src/index.js`에서 DNS를 IPv4 우선(`ipv4first`)으로 두고, 외부 요청 실패 로그에는 실제 원인 코드(`ENETUNREACH`, `ETIMEDOUT` 등)를 함께 남긴다
