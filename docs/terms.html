치유미 이용약관

최종 수정일: 2026-07-28

1. 서비스 소개

치유미(이하 "봇")는 디스코드 서버에서 인증, 치유미코인(가상 재화) 기반 게임(도박, 가위바위보), 치유미코인으로 거래하는 가상 주식 시장, 예금·대출을 제공하는 은행, 채팅/음성 활동 기반 레벨·순위, 리그 오브 레전드 전적검색, 욕설/도배/레이드 검열, 경고 시스템, 입퇴장 알림, 공지, 티켓, 가상 반려동물 키우기, 끝말잇기, AI 대화, 날씨·강수 레이더·지진 정보, 문의/신고/피드백 등의 기능을 제공하는 디스코드 봇입니다.

2. 이용 동의

봇의 명령어를 처음 사용하면 본 약관과 개인정보 처리방침에 대한 동의 안내가 표시됩니다. "동의하기" 버튼을 누르면 본 약관 및 개인정보 처리방침 전체에 동의한 것으로 간주되며, 이후 모든 기능을 이용할 수 있습니다.

3. 이용 조건

봇을 사용함으로써 디스코드의 서비스 약관 및 커뮤니티 가이드라인을 준수하는 데 동의합니다.

4. 치유미코인 및 게임 기능

치유미코인은 실제 화폐로 환전할 수 없는 가상의 재화이며, /도박(슬롯머신, 홀짝, 숫자맞추기, 블랙잭, 가위바위보), /주식(가상 주식 매수·매도), /은행(예금·출금·대출 상환) 등 서버 내 기능에서만 사용됩니다. /출석 명령어로 하루에 한 번 치유미코인과 경험치를 받을 수 있습니다. 운영자는 별도 통지 없이 코인 수치를 초기화하거나 조정할 수 있습니다.

5. 레벨 및 순위 기능

채팅과 음성 채널 활동, /출석을 통해 경험치가 적립되며, 경험치와 레벨, 음성 채널 체류 시간은 서버별로 따로 누적됩니다. 치유미코인은 서버 구분 없이 전체 계정 단위(글로벌)로 누적됩니다. /순위 명령어로 해당 서버에서의 레벨과 순위가 담긴 카드 이미지를 확인할 수 있고, 현재 서버 멤버 한정 채팅·음성 순위도 볼 수 있습니다. 서버 관리자는 레벨업 시 안내할 채널과 문구를 직접 설정할 수 있습니다.

6. 입퇴장 알림 기능

서버 관리자가 /입퇴장에서 설정하면, 멤버가 서버에 입장하거나 퇴장할 때 관리자가 지정한 채널에 커스텀 문구로 알림을 보냅니다. 입장 알림 채널과 퇴장 알림 채널은 각각 따로 지정할 수 있으며, 별도로 설정하지 않으면 공통 채널로 전송됩니다.

7. 전적검색 기능

/전적검색 명령어는 사용자가 입력한 라이엇 ID를 Riot Games의 공식 API에 전달하여 전적 정보를 조회합니다. 본 기능은 Riot Games의 공식 제품이 아니며, Riot Games의 의견이나 입장을 반영하지 않습니다. League of Legends 및 Riot Games는 Riot Games, Inc.의 상표 또는 등록 상표입니다.

8. 욕설/도배/레이드 검열 기능

서버 관리자가 /검열 또는 /로그에서 켜면, 봇은 해당 서버의 모든 채팅을 자동으로 검사하여 욕설로 판단되는 메시지나, 짧은 시간에 반복되는 도배성 메시지를 삭제하고 설정된 로그 채널에 기록을 남깁니다. 욕설 검열과 도배 검열은 각각 따로 켜고 끌 수 있으며, 도배 검열은 1~5단계로 민감도를 조정할 수 있습니다.

레이드 검열을 켜면, 30초 안에 동일한 닉네임을 가진 멤버가 3명 이상 서버에 입장할 경우 레이드로 감지하고 자동으로 모든 채널의 메시지 전송을 차단하며 서버 초대 링크를 일시 정지합니다. 감지 시 관리자 알림 채널과 /로그에 설정된 채널에 경보 내용이 기록되며, /공지로 사용된 채널에 서버 멤버용 공지가 발송됩니다. 서버 관리자는 /검열에서 경보를 해제하면 채널 잠금과 초대 링크 정지가 함께 풀립니다. 레이드 감지 시 설정에 따라 입장한 멤버를 자동으로 킥 또는 밴할 수 있습니다.

9. 경고 시스템

서버 관리자는 /경고 명령어로 멤버에게 경고를 추가하거나 조회·취소·초기화할 수 있습니다. 관리자는 경고 횟수별로 역할 부여, 뮤트(타임아웃), 킥(추방), 영구 밴 등의 제재를 미리 설정해 둘 수 있으며, 경고 지급 시 해당 설정에 따라 자동으로 제재가 적용됩니다. 최대 경고 횟수를 설정한 경우, 그 횟수에 도달하면 자동으로 영구 밴 처리됩니다. 경고 내역은 서버별로 저장됩니다.

10. 문의, 신고, 피드백

/문의 명령어로 제출한 신고, 피드백, 버그 신고 내용(작성자, 서버 이름, 서버 주소, 내용)은 운영자가 지정한 채널로 전달됩니다.

11. 티켓 기능

서버 관리자가 /티켓에서 채널과 안내 문구를 설정하고 메시지를 게시하면, 사용자는 "티켓 생성" 버튼으로 비공개 스레드를 만들 수 있습니다. 이 스레드는 티켓을 생성한 사용자와 해당 서버의 관리 권한이 있는 사용자만 볼 수 있습니다. 스레드 내에는 관리자 전용으로 사용자 추가, 닫기(관리자 외 열람 권한 제거), 대화 내용 텍스트 파일 저장, 삭제 기능이 제공됩니다.

12. 키우기(가상 반려동물) 기능

/키우기 명령어로 가상의 고양이를 키울 수 있습니다. 밥 주기, 씻겨주기, 놀아주기는 각각 하루에 한 번만 가능하며, 결과는 확률에 따라 성공 또는 실패로 갈립니다. 고양이의 성장 단계는 실제 처음 사용한 날로부터 흐른 기간을 기준으로 결정되며, 이 데이터는 서버 구분 없이 계정 단위로 누적됩니다.

13. 주식 기능

/주식 명령어로 치유미 세계관의 가상 회사 주식을 치유미코인으로 거래할 수 있습니다. 주가는 매일 자정(KST)에 자동으로 변동되며, 수익이나 손실을 보장하지 않습니다. 주식은 서버 구분 없이 계정 단위로 보유됩니다. 운영자는 별도 통지 없이 주가 및 주식 데이터를 초기화하거나 조정할 수 있습니다.

14. 은행 기능

/은행 명령어로 치유미코인을 예금하거나 대출받을 수 있습니다. 예금에는 매일 자정 1%의 이자가 자동 지급됩니다. 대출은 1건만 유지할 수 있으며, 대출금에는 매일 자정 5%의 복리 이자가 적용됩니다. 대출 한도는 최대 50,000코인이며, 이자는 상환 시 원금과 함께 지불해야 합니다. 총 자산(지갑 코인 + 예금 + 보유 주식 평가액)이 상환 필요액에 미치지 못하는 경우 파산 신청이 가능하며, 파산 시 지갑 코인이 초기값으로 초기화되고 예금·대출·보유 주식이 모두 소멸됩니다. 파산 이후에는 환생 횟수가 기록됩니다. 운영자는 별도 통지 없이 은행 데이터를 초기화하거나 이자율을 조정할 수 있습니다.

15. 끝말잇기 기능

서버 관리자가 /끝말잇기에서 채널을 설정하면, 사용자는 해당 채널에서 파티를 모집해 끝말잇기 게임을 즐길 수 있습니다. 게임은 스레드에서 진행되며 치유미도 참여자로 함께합니다. 제한 시간 내 올바른 단어를 입력하지 못하면 탈락하며, 게임이 종료되면 스레드는 일정 시간 후 자동 삭제됩니다. 단어 정오답 판정은 끝말잇기 규칙(첫 글자/끝 글자 일치, 중복 단어 제외)과 국립국어원 우리말샘 사전 등재 여부를 함께 확인합니다.

16. 날씨·레이더·지진 기능

채팅 메시지로 도시명과 함께 날씨를 물어보면, 봇은 입력한 도시명을 Open-Meteo 날씨 API 및 대기질 API에 전달하여 기온, 체감온도, 습도, 강수확률, 풍속, 미세먼지(PM2.5) 정보를 조회하고 결과를 표시합니다. 강수 레이더 이미지는 기상청 API 또는 RainViewer 서비스의 타일 데이터를 합성하여 제공합니다. 지진 정보는 한반도 주변 최근 30일간의 지진 발생 현황을 USGS(미국 지질조사국) API 및 기상청 지진정보 조회서비스를 통해 조회하여 표시합니다. 위 기능에서 입력된 도시명은 조회 용도로만 사용되며 별도로 저장되지 않습니다.

17. AI 대화 기능

채팅 메시지가 "유미야"로 시작하는 경우, 봇은 해당 메시지를 Groq의 AI API를 통해 처리하고 응답합니다. AI 응답은 사전에 설정된 성격과 말투를 바탕으로 생성되며, 봇이 직접 작성한 내용이 아닌 AI 생성 결과물입니다. 대화 맥락은 채널별로 메모리에만 임시 보관되며, 봇이 재시작되면 초기화됩니다. 무료 API 한도 관리를 위해 개발자를 제외한 사용자는 1분에 최대 5회까지만 AI 대화를 이용할 수 있습니다.

18. 이용제한

봇 운영자(개발자)는 약관 위반, 악용, 부정 사용 등이 확인될 경우 별도 통지 없이 특정 사용자의 봇 이용을 제한할 수 있습니다. 이용이 제한된 사용자는 봇의 모든 기능을 사용할 수 없습니다.

19. 책임의 한계

봇은 무상으로 제공되며, 운영자는 봇의 가용성이나 정확성을 보증하지 않습니다. 봇 사용으로 발생하는 손해에 대해 운영자는 책임을 지지 않습니다.

20. 약관의 변경

본 약관은 사전 통지 없이 변경될 수 있습니다. 변경된 약관은 본 페이지에 게시된 시점부터 적용됩니다.
